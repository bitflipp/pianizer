Pianizer MIDI Diagnostic

Lists every Web MIDI input/output port (not just what Pianizer's output picker shows), sends test notes, and logs any incoming MIDI message with the elapsed time since the note was sent — so you can see whether the Disklavier echoes hammer-sensor timing back on a second port. Must be served over http://localhost (Web MIDI needs a secure context).
